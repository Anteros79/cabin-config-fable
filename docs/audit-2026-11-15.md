## How to read the status column

- **C** confirmed: reproduced by running a probe or a request against a disposable instance.
- **R** confirmed by reading: the code path is unambiguous; nothing was run.
- **P** plausible: follows from the code but needs a condition that was not reproduced.

Line numbers are as of `5d6679d` and will drift; locate by symbol.

Severity: **S1** wrong result, data loss or security exposure; **S2** broken behaviour with a workaround; **S3** robustness, operability or polish.
